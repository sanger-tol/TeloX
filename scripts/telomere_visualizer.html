📋 Instructions:

  1. Run TeloX: ./target/release/telox genome.fasta --annotate
  2. Upload the generated telox_genome_telomeres.bed file above
  3. Use filters to explore specific chromosomes, motifs, or strands
  4. Hover over points for detailed information

🎨 Features:

  • Interactive plots - Zoom, pan, hover for details
  • Filtering - Focus on specific chromosomes, motifs, or strands
  • Color coding - Red for forward (+), blue for reverse (-)
  • Statistics - Real-time summary of filtered data
  • No dependencies - Works in any modern web browser
